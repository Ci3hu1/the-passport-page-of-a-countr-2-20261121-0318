The open passport of the Republic of Caelmar — a tide republic whose territory exists only at low tide — held by Mara Iversen, Warden of the Sands. A complete invented spread: data page with portrait and machine-readable strip, stamps from North Sea neighbours that agree with the issue date, a map of the sandbank, and one telling detail: the passport is valid only while the country is above water.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024x1024) to `$MAKEFUN_OUTPUT_DIR`, `/output`, or the working directory — first location that succeeds. Pure Python standard library; the spread is bundled as `entry.png`.
